영어 학습 PWA - OpenAI 직접 호출(Local-only 구조)

포함 기능
- Gemini 제거
- Netlify Function / 서버 Proxy 제거
- 브라우저에서 OpenAI API 직접 호출
- 쉐도잉 탭: GPT TTS 듣기 + 녹음 + 발음/억양 피드백
- 문제답변 탭: GPT 피드백 + 자연스러운 문장 듣기 + 따라읽기 녹음 + 발음 피드백
- 퀴즈 탭: GPT 기반 생성/채점

중요
- 이 ZIP은 Netlify 서버 기능을 쓰지 않습니다.
- 기존 Netlify 사이트가 Usage Limit로 멈춘 경우, 같은 사이트 주소로는 접속이 안 됩니다.
- 새 사이트로 다시 배포하거나, 다른 무료 호스팅(GitHub Pages/Vercel/새 Netlify site)에 올려야 합니다.
- iPhone 홈화면 앱은 기존 아이콘 삭제 후 새 주소에서 다시 '홈 화면에 추가'하세요.

API Key
- OpenAI API key(sk-...)를 앱 첫 화면에 입력 후 저장하세요.
- 키 생성 자체는 무료이고, 실제 사용량에 대해서만 과금됩니다.
